# Auto-index frontmatter

Section indexes (`architecture/`, `backend/`, `frontend/`, `implementation-plans/`)
are generated by `docs/gen_indexes.py`, which `make build-docs` and
`make serve-docs` run before Zensical. Add YAML frontmatter to any plan or
page so it appears in the right group with rich metadata.

## Schema

```yaml
---
status: delivered # delivered | in-progress | abandoned
issue: 310-b
last_updated: 2026-05-05
summary: One-line description.
---
```

All keys are optional. Files missing `status` land under **Uncategorized**;
files missing `title` fall back to the first `# H1` heading, then the
filename stem.

## Trigger a rebuild

Local preview:

```bash
cd docs
make serve-docs
```

The indexes are written once, at start: restart `make serve-docs` to see
a new plan or a changed status. CI runs `make build-docs`. A missing
`status` lands under "Uncategorized"; an unknown one, or unparseable
frontmatter, fails the build.

## Where output lands

The script writes `src/<section>/_index.md` (gitignored). Open
`site/<section>/_index.html` after a build to inspect the output.
